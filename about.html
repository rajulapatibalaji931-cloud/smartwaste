About the Project

Smart Waste Management System is a college-project frontend prototype demonstrating how web technologies can connect citizens with municipal waste-management teams.

Citizens can report waste problems, track complaint progress and locate public bins. Administrators can monitor complaints, update statuses and review bin fill levels.
